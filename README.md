# Синапс

Учебная игра по блочному программированию на C# / Blazor WebAssembly / .NET 10.
Игрок собирает граф из блоков и проверяет его на тестах задания.

## Структура

- `Client/` — фронтенд: игра, главная, справка и интерфейс админки.
- `Server/` — бэкенд ASP.NET Core: API кампании, вход администратора и сохранение уровней.
- `Shared/` — общие модели уровней, тестов и блоков.

Сервер раздаёт фронтенд и API с одного адреса. Прогресс игрока и собранные схемы хранятся в браузере. Общая кампания хранится на сервере.
Главная страница содержит список заданий и прогресс без 3D-сцены и WebGL.

## Запуск

Нужен .NET 10 SDK. Откройте `Synapse.Blocks.slnx` и выберите `Synapse.Blocks.Server` стартовым проектом.
Перед первым запуском задайте собственный пароль администратора (от 12 символов):

```powershell
dotnet user-secrets set "Admin:Password" "ЗАМЕНИТЕ-НА-СВОЙ-ПАРОЛЬ" --project Server
dotnet run --project Server
```

Откройте http://localhost:5024. В режиме разработки используется HTTP.
Админка: http://localhost:5024/admin, редактор: http://localhost:5024/admin/levels (также доступен `/editor`).
Пароль задаётся только на сервере и не попадает в исходники фронтенда.

## Создание уровней

1. Откройте `/admin` и войдите с заданным паролем.
2. Перейдите в редактор и нажмите «＋» рядом со списком уровней.
3. Заполните задание, выберите блоки, добавьте тесты и при необходимости вступительные пояснения.
4. Нажмите «Сохранить кампанию». Изменения увидят игроки после открытия или обновления игры.

В редакторе доступны копирование, удаление и перестановка уровней, импорт и экспорт JSON.
Изменения, включая импорт и удаление, публикуются только кнопкой сохранения.
Экспорт позволяет скачать резервную копию без публикации правок.
Если кампания была изменена в другой вкладке, сервер отклонит сохранение: экспортируйте свои правки, загрузите актуальную кампанию и перенесите изменения.
Сессия администратора действует 8 часов. После истечения сессии экспортируйте несохранённые правки перед повторным входом.

## Данные

При первом обращении к кампании сервер создаёт `Server/App_Data/levels.json` из `Server/Data/seed-levels.json`.
Последующие сохранения атомарно заменяют серверный файл. Перезапуск приложения сохраняет уровни.
Каталог `App_Data` исключён из Git и недоступен как статический контент.

Для другого расположения укажите абсолютный путь в переменной `Storage__Directory`.
Файловое хранилище рассчитано на один процесс сервера. При нескольких экземплярах потребуется общая база данных.
При переносе или обновлении сервера сохраняйте каталог данных и делайте его резервные копии.

Выполнение схем, отладка и проверка решений пока происходят в браузере. «Скрытые» тесты скрываются в интерфейсе, но доступны в данных API; это учебная игра, а не защищённая система экзаменов.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/levels` | Кампания для игры |
| GET | `/api/admin/session` | Состояние входа |
| POST | `/api/admin/login` | Вход: JSON `{ "password": "..." }` |
| POST | `/api/admin/logout` | Выход |
| GET | `/api/admin/levels` | Кампания для редактора и заголовок `ETag` |
| PUT | `/api/admin/levels` | Сохранение массива уровней с `If-Match`, полученным при загрузке |

Административные чтение и запись требуют cookie сессии. POST и PUT дополнительно требуют заголовок `X-Synapse-Request: 1`; доступ с других origins не включён. Попытки входа ограничены по IP.

## Проверка и публикация

```powershell
dotnet build Synapse.Blocks.slnx
pwsh -File tests/smoke.ps1
dotnet publish Server -c Release -o artifacts/server
pwsh -File tests/smoke.ps1 -ServerDirectory artifacts/server
```

Для сервера задайте `Admin__Password` через секреты хостинга, `Storage__Directory` для постоянных данных и HTTPS.
User-secrets используются только в режиме Development. В production cookie администратора передаётся только по HTTPS.
Публикуйте сервер вместе с его `wwwroot`, а не отдельно клиент.
GitHub Pages не выполняет ASP.NET Core: для этой версии нужен хостинг с .NET 10.
GitHub Actions проверяет и собирает серверный артефакт, автоматическая публикация в Pages удалена.
