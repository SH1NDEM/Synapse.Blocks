# Режимы кампании: дети и обычная версия — дизайн

## Цель

Сайт предлагает на главной странице два независимых режима: обычную кампанию и кампанию для детей 1–3 класса. Каждый режим загружает собственный JSON уровней и хранит отдельный прогресс и черновики программ в браузере.

## Данные уровней

- `wwwroot/levels-adult.json` — текущая кампания из 10 обычных уровней без изменения их сложности.
- `wwwroot/levels-kids.json` — отдельная кампания из 8 уровней. Уровни 01 и 02 повторяют базовые действия из текущей игры в детской формулировке. Уровни A–Е добавляются после них и получают буквенные обозначения в интерфейсе.
- Во всех детских тестах используются только целые неотрицательные числа от 0 до 10. Нет степеней, отрицательных чисел, дробей, типов данных и переменных.
- Первое объяснение условия показывается перед уровнем C. Оно использует существующее вступительное окно и рассказывает о синей ветке «условие выполнено» и красной ветке «условие не выполнено».
- Первое объяснение цикла показывается перед уровнем D. Оно использует существующее вступительное окно и рассказывает, что порт «тело» запускает цепочку блоков несколько раз, а «после цикла» продолжает программу.

## Детская последовательность

| Обозначение | Название | Блоки | Результат |
| --- | --- | --- | --- |
| 01 | Передай число | Вход, Выход | вернуть число без изменения |
| 02 | Усиль сигнал | Вход, Действие, Выход | умножить число на 3 |
| A | Ещё один кубик | Вход, Действие, Выход | прибавить 1 |
| Б | Две наклейки | Вход, Действие, Выход | прибавить 2 |
| C | Высокая башня | Вход, Условие, Действие, Выход | если больше 5 — «высокая», иначе «низкая» |
| D | Три шага | Вход, Цикл, Действие, Выход | три раза прибавить 1 |
| E | Удвоитель | Вход, Цикл, Действие, Выход | повторить «прибавить 1» столько раз, сколько дано на входе; результат `2 × вход` |
| F | Шесть конфет | Вход, Цикл, Действие, Выход | три раза прибавить 2 |

## Выбор режима

На главной странице рядом с запуском кампании отображаются две ясные карточки:

- «Для детей 1–3 класс» — включает детский набор;
- «Обычная версия» — включает обычный набор.

Нажатие сохраняет режим в `localStorage`, затем переводит игрока в кампанию. Выбранная карточка явно отмечена. Без сохранённого выбора сайт использует обычную кампанию как безопасное поведение для старых ссылок и уже открытой страницы игры.

## Хранение в браузере

- Обычная кампания продолжает использовать существующие ключи прогресса и решений: старые данные не теряются.
- Детская кампания использует ключи с отдельным префиксом, поэтому решения и пройденные уровни не могут попасть в обычный режим и наоборот.
- Кнопка «Сбросить прогресс» очищает только активный режим: его прогресс и его черновики решений. Редактор уровней и сцена города не затрагиваются.

## Админка

Редактор уровней получает переключатель набора «Обычная / Дети». Он загружает выбранный JSON и скачивает его под соответствующим именем. Это позволяет редактировать обе кампании через существующий редактор, а не вручную менять файл.

## Технические компоненты

- `CampaignModeStore` — один сервис для чтения, выбора и проверки активного режима.
- `LevelStore` — выбирает `levels-adult.json` или `levels-kids.json` по активному режиму и может загружать JSON конкретного режима для редактора.
- `ProgressStore` и `SolutionStore` — получают режим и строят из него изолированный ключ localStorage.
- `Landing`, `Home`, `LevelEditor`, `MainLayout` — используют сервис вместо неявного единственного набора уровней.

## Проверка

- Автоматические проверки подтверждают правильное имя файла, выбор набора и раздельные ключи хранения.
- JSON обоих наборов проходит десериализацию.
- Исполнитель графов прогоняет образцовые решения всех восьми детских заданий против их тестов.
- Финально выполняются `dotnet build Synapse.Blocks.slnx` и проверка пробелов в diff.
