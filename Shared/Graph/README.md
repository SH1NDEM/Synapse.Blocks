# Ядро графа (Synapse.Blocks.Graph)

Новая модель программ: блоки соединяются **двумя видами проводов**.

- **Провод исполнения** задаёт порядок действий: «Вход → Условие → Выход».
- **Провод данных** передаёт значение от выхода одного блока ко входу другого.

## Из чего состоит

| Файл | Что внутри |
| --- | --- |
| `Value.cs` | `Value` — значение на проводе данных (пусто, логическое, число, текст, список), разбор и сравнение |
| `Ports.cs` | `PortDef`, типы данных и правила их совместимости |
| `NodeDefinition.cs` | базовый класс вида блока, настройки (`ParamDef`), `ExecResult`, категории |
| `NodeRegistry.cs` | каталог видов блоков |
| `GraphModel.cs` | данные программы: `GraphProgram`, `GraphNode`, `GraphLink`, `GraphVariable` |
| `GraphRunner.cs` | интерпретатор, `NodeContext`, результаты запуска и шаги отладки |
| `GraphValidator.cs` | общие проверки структуры и `GraphAnalysis` (достижимость, тела циклов) |
| `GraphRules.cs` | учебные ограничения уровня («нужен цикл», «не больше 2 арифметических блоков») |
| `GraphBuilder.cs` | сборка программ из кода и JSON-сериализация без reflection |
| `Nodes/BuiltInNodes.cs` | встроенные блоки |

## Два вида блоков

**Блок исполнения** имеет порты Exec и реализует `Execute`. Он получает управление по проводу
исполнения, читает входы, может записать выходы и выбирает, куда идти дальше:

- `ExecResult.Next("port")` — перейти по выходу;
- `ExecResult.Enter("body")` — войти во вложенную ветку (тело цикла). Когда ветка кончается
  (её последний выход не подключён), управление само возвращается в блок, и он выполняется снова;
- `ExecResult.Finish(value)` — завершить программу.

Значения выходов блока исполнения запоминаются после его выполнения.

**Чистый блок** имеет только порты данных и реализует `Evaluate`. Он вычисляется по требованию, когда
его значение понадобилось, и пересчитывается на каждом шаге, поэтому видит актуальные переменные
и номер повтора цикла.

## Входы данных

Неподключённый вход берёт значение, введённое прямо в блоке (`GraphNode.Params[portId]`), если у порта
есть `InlineDefault`. Иначе вход обязательно подключается проводом. Значение приводится к типу порта:
любое значение превращается в текст, а текст в число — если это число.

## Как добавить блок

```csharp
public sealed class SquareNode : NodeDefinition
{
    public override string TypeId => "square";
    public override string Label => "Квадрат";
    public override string Category => NodeCategories.Math;
    public override IReadOnlyList<PortDef> Ports { get; } =
    [
        Port.Inline("x", "x", DataType.Number, "2"),
        Port.DataOut("result", "x²", DataType.Number),
    ];

    public override Value Evaluate(NodeContext context, string outputPort)
    {
        var x = context.Number("x");
        return Value.FromNumber(x * x);
    }
}
```

Затем зарегистрируйте его в `BuiltInNodes.RegisterAll`. Интерпретатор, валидатор и правила уровня
подхватят его без изменений. Ошибки для игрока бросайте так: `throw context.Error("Понятный текст")`.

## Встроенные блоки

| TypeId | Блок | Вид |
| --- | --- | --- |
| `start` | Вход | исполнение, начало программы |
| `output` | Выход | исполнение, конец программы |
| `if` | Условие | исполнение |
| `repeat` | Повторить N раз (выход «номер повтора» с 1) | исполнение, тело цикла |
| `while` | Пока | исполнение, тело цикла |
| `for-each` | Для каждого элемента списка | исполнение, тело цикла |
| `set-var`, `change-var` | Записать, изменить переменную | исполнение |
| `get-var` | Переменная | чистый |
| `const` | Значение | чистый |
| `math` | Арифметика `+ - * / %` | чистый |
| `compare` | Сравнение | чистый |
| `logic`, `not` | И / ИЛИ, НЕ | чистый |
| `is-type` | Проверка типа | чистый |
| `text-check`, `join`, `length` | Поиск в тексте, склеить, длина | чистый |
| `list-item` | Элемент списка (номер с 1) | чистый |
